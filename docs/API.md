# Supervisor API

**État : à définir.**

Cette documentation décrira l'API propre à Stream Supervisor une fois la stack applicative choisie.

Principes prévus :
- aucune clé ou credential moteur envoyé au navigateur ;
- contrôle d'accès selon le rôle ;
- opérations privilégiées journalisées ;
- endpoints moteurs encapsulés par les adaptateurs plutôt qu'exposés directement.
